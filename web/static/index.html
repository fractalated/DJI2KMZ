DJI2KMZ — Web

Batch-convert DJI flight logs (.txt) into flight-path KMZ files, right in your browser — nothing is uploaded anywhere except a small decryption-key lookup DJI requires for newer (encrypted) logs.

No folder chosen

Everything else in the folder (photos, videos, other file types) is ignored — only .txt files are converted.

Requires Chrome or Edge (File System Access API). A KMZs/{project}/{date}/ folder and a Pilot Logs/Flight Log.xlsx spreadsheet are created directly inside whatever folder you choose here — nothing is zipped or downloaded.
